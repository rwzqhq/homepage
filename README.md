# 起始页 · Limestart Homepage

一个干净的浏览器起始页。

壁纸默认取**必应「每日一图」**，每天自动同步更新（见下文「必应每日一图」）。

## 功能

| 区域 | 说明 |
| --- | --- |
| 时钟 | 70px 白色大时钟，点击可切换是否显示秒数 |
| 搜索 | 默认聚焦并展开；失焦自动收成 530/230px 胶囊，悬停展开；支持直接输入网址 |
| 搜索引擎 | 百度 / 必应 / 谷歌 / Yandex / 搜狗 / 360，`Alt+1~6` 快速切换，「搜索引擎偏好」可设默认 |
| 文案卡片 | 悬停显示毛玻璃卡片、出处与「⋯」菜单（换一句 / 复制） |
| 捷径 Dock | 悬停显示气泡提示，拖拽可排序；内置「所有捷径 / 壁纸 / 深色主题」 |
| 所有捷径 | 网格化捷径管理页，可新增、编辑、删除（`+` 磁贴） |
| **必应每日一图** | **背景默认跟随必应首页图片，每天自动更新；可查看最近 8 天、固定其中一天、切 4K 原图** |
| 自定义壁纸 | 支持填写任意在线图片地址（会先校验能否加载） |
| 内置壁纸 | 7 张本地壁纸（均为必应每日一图历史图片），离线兜底 |
| 深色主题 | 一键切换，整套色板（含毛玻璃、搜索框、Dock、弹窗）自动切换并记忆 |

## 必应每日一图（每天自动更新）

起始页每次打开都会调用必应的每日一图接口，把背景换成必应当天在用的那张图。

壁纸弹窗里可以：`每天自动更新` 开关、`立即同步`、`4K 原图`（UHD 原图，更清晰、体积更大），
以及最近 8 天的缩略图 —— 点任意一天即固定使用那天的图片（相当于把它当成一张普通壁纸）。

## 键盘操作

| 快捷键 | 作用 |
| --- | --- |
| `Alt` + `1` ~ `6` | 切换搜索引擎 |
| `Ctrl/⌘` + `K` 或 `/` | 聚焦搜索框 |
| `Enter` | 搜索；若输入的是域名（如 `github.com`）则直接打开 |
| `Esc` | 关闭弹窗 / 面板 / 菜单 |

## 壁纸来源

- 在线壁纸来自**必应每日一图**，版权归原作者所有，仅供个人起始页使用；
- 内置的 7 张本地壁纸同样是必应每日一图的历史图片（`public/wallpapers/`），
  作为离线兜底，另含一张项目自带的插画壁纸（`fantasy-valley`，取自本仓库此前的 `bg.jpg`）；
- 壁纸弹窗底部会显示当前壁纸的标题、版权（可点开必应介绍页）与更新方式。

## 技术栈与目录

React 19 + Vite 8 + TypeScript，纯 CSS（CSS 变量即设计 token），运行时无第三方依赖。

构建产物：`dist/` 里只有 `index.html`（自包含，含内联 JS/CSS）、`favicon.svg` 与 `wallpapers/`。
为了让「双击打开」和「静态托管」都能用，做了三件事：

- `base: './'` —— 资源走相对路径，放在任意子目录或 `file://` 下都不会找错文件；
- JS 打成 IIFE、连同 CSS 一起内联进 HTML（`server/inlineSingleFile.ts`）——
  `file://` 下 Chrome 会以 CORS 为由拦掉 `<script type="module">` 与外部样式表，
  换成普通内联脚本后双击即可运行；内联脚本放在 `</body>` 之前，保证 DOM 已解析；
- 内置壁纸路径由 `import.meta.env.BASE_URL` 拼出：开发时 `/wallpapers/…`，构建后 `./wallpapers/…`。

```
src/
  components/     # Background（交叉淡入）/ Clock / SearchBar / QuoteCard / Dock / 网格 / 弹窗
  data/           # 搜索引擎、诗词文案、内置壁纸、默认捷径
  lib/            # bingDaily（每日一图数据源 + 缓存）、useBingDaily（每日同步）、搜索解析、storage、时钟
  styles/         # tokens.css（设计变量）、base.css、menu.css
server/
  bingDailyProxy.ts   # dev / preview 的 /api/bing-daily 中间件
  inlineSingleFile.ts # 构建后把 JS / CSS 内联进 index.html
public/
  wallpapers/     # 7 张内置壁纸 + 缩略图
docs/
  reference/      # 参考站点截图（设计依据）
  screens/        # 本实现的验证截图
_qa/
  daily.mjs       # 每日壁纸端到端检查（Playwright + 本机 Chrome）
  fallback.mjs    # 去掉本机代理后的镜像回退检查
  open-modes.mjs  # 四种打开方式（file:// / preview / dev）渲染对比
  file-open.mjs   # 双击 dist/index.html 时的同步、弹窗与本地存储检查
```

  壁纸切换与刷新后保持、深色主题持久化、捷径新增/删除/拖拽排序、Dock 气泡提示。
- 每日一图专项验证（`node _qa/daily.mjs`，默认跑在 `http://localhost:4173`）：

  | 场景 | 期望 | 结果 |
  | --- | --- | --- |
  | 首次打开 | 背景为必应当天图片，来源＝官方接口，无控制台报错 | ✅ |
